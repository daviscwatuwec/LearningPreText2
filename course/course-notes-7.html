    Our goal is the proof Theorem 5 Recall what it says
    🔗
    Solution 1.
    A bounded function \(f:[a,b]\to \R\) is integrable if and only if \(\discont(f)\) has measure zero.
    🔗
    🔗
    We have already proven one direction
    🔗
    Solution 2.
    We’ve already proven that integrability implies that the set of discontinuities is measure 0.
    🔗
    🔗
    We still need to prove the reverse:
    🔗
    Solution 3.
    We need to prove that if the set of discontinuities is measure zero then \(f\) is integrable
    🔗
    🔗
    We will need two more propositions in our argument The first says that if you can bound the oscillation at every point, then you control the difference between the upper and lower integrals.
    🔗

    Proposition 10.

    Let \(\alpha\gt0\text{,}\) \(f:[a,b]\to \R\) be bounded and satisfy that \(\osc(f,x)\lt \alpha\text{.}\) Then \(\overint_a^b f~dx-\lowerint_a^b f~dx\le \alpha\cdot(b-a)\)
    🔗
    🔗
    The second says that \(\discont(f,\alpha)\) is compact (Recall what "compact" means, as well as a theorem from analysis I that says excactly what sets are compact
    🔗
    Solution 4.
    A set being "compact" means that every open cover has a finite subcover. In analysis I you proved that a subset of \(\mathbb{R}\) is compact if and only if it is closed and bounded.
    🔗
    🔗

    Proposition 11.

    Let \(f:[a,b]\to \R\) be a function and \(\alpha\gt0\text{.}\) Then \(\discont(f,\alpha)\) is compact. (Even though \(\discont(f)\) might not be)
    🔗

    A bit more space for the proof that \(m^*(\discont(f)=0)\implies\) integrability.

    🔗
    🔗
    Proving Proposition 10
    🔗
    Let \(\alpha\gt0\text{,}\) \(f:[a,b]\to \R\) be bounded and satisfy that \(\osc(f,x)\lt \alpha\text{.}\) We need to show that \(\overint_a^b f~dx-\lowerint_a^b f~dx\le \alpha\cdot(b-a)\)
    🔗
    We need a lemma
    🔗

    Lemma 13.

    Let \(\alpha\gt0\text{,}\) \(f:[a,b]\to \R\) be bounded and satisfy that \(\osc(f,x)\lt \alpha\text{.}\) For any \(\epsilon\gt0\text{,}\) there is a single \(\delta\gt0\) so that for every intervals \(I\subseteq [a,b]\) with length \(\ell(I)\lt \delta\text{,}\) \(\osc(f,I)\lt\alpha+\epsilon\)
    🔗
    🔗

    Proof of Proposition 10 assuming Lemma 13.

    We get to assume all of the hypotheses of Lemma 13. Consider any \(\epsion\gt0\) and let \(\delta\gt0\) be the positive number produced by the Lemma. Let \(P=\{x_0,\dots, x_n\}\) be a partition of \([a,b]\) into intervals each with length less than \(\delta\text{.}\) Complete the proof.
    🔗
    Solution.
    \(U(f,P)-L(f,P) = \Sum_{i=1}^n (M(f,[x_{i-1}, x_i])-m(f,[x_{i-1}, x_i]))\cdot (x_{i}-x_{i-1})= \Sum_{i=1}^n (\osc(f, [x_{i-1},x_i]))\cdot (x_{i}-x_{i-1})\text{.}\) We required that the length of \([x_{i-1},x_i]\) is less than \(\delta\text{,}\) which we chose using Lemma 13. Thus, \(\osc(f, [x_{i-1},x_i]))\lt\alpha\) and so \(U(f,P)-L(f,P)\lt \Sum_{i=1}^n\alpha\cdot (x_{i}-x_{i-1}) = \alpha\cdot (b-a)\text{.}\) Since \(\overint_a^b f~dx-\lowerint_a^b f \le U(f,P)-L(f,P)\) this completes the proof.
    🔗

    Proof of Lemma 13.

    We will use compactness. Recall what we mean when we say that \([a,b]\) is compact.
    🔗
    Let \(x\in [a,b]\text{.}\) Write down the limit definition of \(\osc(f,x)\) and use it to build a different choice of \(\delta\) for each \(x\text{.}\)
    🔗
    Solution 1.
    \(\Lim_{h\to 0}\osc(f,x-h,x+h) = \osc(f,x_0)\lt \alpha\text{.}\) So there is a \(\delta(x)\gt0\) so that for all \(h\lt \delta(x)\text{,}\) \(\osc(f,(x-h,x+h))\lt \alpha\text{.}\)
    🔗
    🔗
    Maybe you want to tke the minimum of these \(\delta\)’s, but there are infinitely many. Use compact to get them down to a finite list. For technical reasons, divide the \(\delta\)’s by 2.
    🔗
    Solution 2.
    \(\{(x-\delta(x),x+\delta(x))\mid x\in [a,b]\}\) is an open cover of \([a,b]\text{.}\) So, it has a finite subcover, \(\{(x_i-\delta(x_i)/,x_i+\delta(x_i)/)\mid i=1,\dots,n\}\text{.}\)
    🔗
    🔗
    Let \(\delta = \min(\delta(x_1)/2,\dots\delta(x_n)/2)\) and \(I\subseteq [a,b]\) be a subset of length less that \(\delta\text{.}\) Argue that \(I\subseteq (x_i-\delta(x_i), x_i+\delta(x_i))\) for some \(i\text{.}\)
    🔗
    Solution 3.
    Let \(I=[u,v]\text{.}\) Then \(u\in(x_i-\delta(x_i)/2, x_i+\delta(x_i)/2)\) for some \(i\text{.}\) Since \(v-u=\ell(I)\lt \delta\le \delta(x_i)\text{.}\)this means that \(|v-x_i|\le|v-u|+|u-x_i|\lt\delta\text{.}\)
    🔗
    🔗
    Finish the proof
    🔗
    Solution 4.
    Since \(I\le (x_i-\delta(x_i), x_i+\delta(x_i))\text{,}\) \(\osc(f,I)\le \osc(f, (x_i-\delta(x_i), x_i+\delta(x_i)))\lt \epsilon\text{.}\)
