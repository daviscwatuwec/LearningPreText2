    3. An uncountable measure zero set The famous "Cantor set" or "Cantor dust" has a few equivalent definitions:
      🔗
      1. The set of all real numbers which have base 3 expansions containing only 0 and 2 (so \(.020020002\_3\) is in the Cantor set, but \(0.1201\) is not. Note that \(0.1=0.022222\dots\) is in the Cantor set)
        🔗
        🔗
      2. (A recursive definition) For a set \(X\) and \(a,b\in \R\) define \(aX+b = \{ax+b\mid x\in X\}\text{.}\) Define a sequence of sets by \(C_0=[0,1], C_{n+1} = \frac{1}{3}C_n \cup (\frac{1}{3}C_n+\frac{2}{3})\text{.}\) Cantor’s set is given by \(C=\cap_{n=1}^\infty C_n\)
        🔗
        🔗
