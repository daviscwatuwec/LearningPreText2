    Handout Riemann Lebesgue part 1 homework (optional)
    

    1. Pull up a graph of \(\phi(x) = \frac{1}{x}\cdot \sin\left(\frac{1}{x}\right)\) in your favourite graphing utility (Maybe desmos). Tell me what \(\osc(\phi,0)\) is and write a few sentences justifying your conclusion
      🔗
      🔗
    2. Recall the indicator function for \(\mathbb{Q}\text{,}\) \(\chi_{\Q}(x)=\begin{cases}1\amp x\in \Q\\0\amp x\notin \Q\end{cases}\text{.}\) Prove that \(\osc(\chi_\Q,x)=1\) for all \(x\in \R\)
      🔗
      🔗
    3. We mentioned in the notes that there is a gap. It is not the case that if \(x\in \discont(f,\alpha)\) and \(x\in I_k\) then \(\osc(f, I_k)> \alpha\text{.}\) Prove the following
      🔗
      Claim if \(x\in \discont(f,\alpha)\) and \(x\in I_k\) then either \(x\) is en endpoint of \(I_k\) or \(\osc(f, I_k)> \alpha\text{.}\)
      🔗
      🔗
    4. Use the obsevation above to fix the proof we did in the notes of the following. Claim If \(f:[a,b]\to \R\) is integrable then \(m^*(\discont(f))=0\text{.}\)
      🔗
      Hint: Instead of using the open cover \(\I=\{I_k\mid k\in Z_{\alpha}\}\text{,}\) try
      \begin{equation*} I=\{I_k\mid k\in Z_{\alpha}\}\cup\{(x_i-\text{small}, x_i+\text{small})\mid i=0,\dots n\} \end{equation*}
      where "small" you need to pick and \(P=\{x_0,\dots, x_n\}\text{.}\)
      🔗
