    Section Starting the Riemann-Lebesgue theorem on integrability

    Handout Integrability implies \(\discont(f)\) has measure zero.
    

    Here are two things you will remember from the unit on the Riemann integral:
    • Solution.
      Every continuous function is integrable
      🔗
      🔗
      🔗
    🔗
    • Solution.
      The indicator function for the rationals \(\chi_\Q\) is not integrable. It is also discontinuous at every point in \(\R\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    This suggests the following. Perhaps a function is integrable if and only if it is "not too" discontinuous.
    🔗

    Theorem 5. The Riemann Lebesgue theoremm.

    A function \(f:[a,b]\to \R\) is integrable over \([a,b]\) if and only if \(m^*(\discont(f))=0\)
    🔗
    🔗
    Here \(\discont(f)\) means
    🔗
    Solution 1.
    \(\discont(f)\) is the set of all inputs where \(f\) is discontinuous.
    🔗
    🔗
    Not a proof, but an idea:
    🔗
    Recall a condition involving partitions that is equivalent to a function being integrable.
    🔗
    Solution 2.
    \(f\) is integrable if and only if for every \(\epsilon\gt 0\) there is a partition \(P\) with \(U(f,P)-L(f,P)\lt\epsilon\)
    🔗
    🔗
    If we want to show that \(m^*(\discont(f))=0\) then what do we need to show?
    🔗
    Solution 3.
    \(m^*(\discont(f))=0\) if and only if for every \(\epsilon\gt 0\) there is an countable cover \(\I\) of \(\discont(f)\) by open intervals with \(\ell(\I) \lt \epsilon\)
    🔗
    🔗
    So give an idea:
    🔗
    Solution 4.
    Well, a partition is made out of intervals. Maybe we can use a partition which has \(U(f,P)-L(P,f)\lt \epsilon\) to build an open cover of the set of discontinuities which has very little length.
    🔗
    🔗
    In order to make this work, we will need a few more details.
    🔗

    Definition 6.

    For an interval \(I\text{,}\) the net oscillation of a function \(f\) over \(I\) is given by \(\osc(f,I) = \Blank{2cm}\text{.}\) The oscillation of \(f\) at a point \(x_0\) is given by \(\osc(f,x_0) = \Blank{2cm}\)
    🔗
    Solution.
    \(\osc(f, I) = \sup(f(I))-\inf(f(I))\text{,}\) \(\osc(f,x_0)=\Lim_{h\to 0}\osc(f,(x_0-h,x_0+h))\)
    🔗
    🔗
    🔗
    • Examples: Explain why \(\osc(\sin(x), [0,\pi])=1\) and \(\osc(\sin(1/x), 0)=2\)
      🔗
      Solution.
      \(\sup(\{\sin(x)\mid x\in [0,\pi]\})=1\) and \(\inf(\{\sin(x)\mid x\in [0,\pi]\})=0\text{,}\) so \(\osc(\sin(x),[0,2\pi]) = 1-0=1\)
      🔗
      Let \(f(x)=\sin(1/x)\) and \(I=(-\epsilon,\epsilon)\text{.}\) There are some \(a,b\in (-\epsilon, \epsilon)\) with \(f(a)=1\) and \(f(b)=-1\text{.}\) (Get explicit values if your like.) Thus \(\sup(f[I])\ge 1\) and \(\inf(f[I])\le 1\text{.}\) You can make these equality by remembering that the max and min values of \(\sin\) are \(\pm1\text{.}\) Thus, \(\osc(\sin(1/x), (-\epsilon,\epsilon))=1-(-1)= 2\text{.}\) Take the limit as \(\epsilon\to 0\) to get \(\osc(f,0)=0\)
      🔗
      🔗
      🔗

    Proposition 8.

    \(f\) is discontinuous at \(x_0\) if and only if \(\osc(f,x_0)>0\)
    🔗
    🔗

    Proof.

    Think about the contrapositive. (\(f\) is continuous at \(x_0\) iff \(\osc(f,x_0)=0\))
    🔗
    Solution.
    Suppose \(f\) is continuous and let \(\epsilon\gt0\text{.}\) There is a \(\delta\gt0\) so that for all \(x\) if \(|x-x_0|\lt\delta\) then \(|x-x_0|\lt\delta\text{.}\) But this means that for all \(x\in (x_0-\delta, x_0+\delta)\text{,}\) \(f(x_0)-\epsilon\lt f(x)\lt f(x_0)+\epsilon\text{.}\) But then \(f(x_0)-\epsilon\lt \inf(f((x_0-\delta, x_0+\delta)))\le\sup(f((x_0-\delta, x_0+\delta)))\lt f(x_0)+\epsilon\text{.}\) This can be used to show that \(0\le \sup(f((x_0-\delta, x_0+\delta)))-\inf(f((x_0-\delta, x_0+\delta)))\lt 2\epsilon\text{.}\) Divide \(\epsilon\) by 2 to conclude that \(\osc(f,x_0)=0\text{.}\)
    🔗
    Suppose \(\osc(f,x_0)=0\) is continuous and let \(\epsilon\gt0\text{.}\) Since \(\osc\) is defined to be a limit. There is some \(\delta\gt0\) so that for all \(h\text{,}\) if \(|h|\lt\delta\) then \(\osc(f,(x_0-\delta, x_0+\delta))\lt \epsilon\text{.}\) Set \(I=(x_0-\delta, x_0+\delta)\) But then for any \(x\text{,}\) if \(|x-x_0|\lt \delta\) then \(f(x),f(x_0)\in (\inf(f(I)), \sup(f(I)))\text{,}\) which by has length less that \(\epsilon\text{.}\) But that means that \(|f(x)-f(x_0)|\lt \epsilon\)
    🔗
    🔗
    🔗
    Inspired by this, for any \(\alpha\gt0\) we will set \(\discont(f,\alpha)\) to be the set of all \(x\) with \(\osc(f,x)\ge\alpha\text{.}\)
    🔗

    Corollary 9.

    \(\discont(f) = \Cup_{n=1}^\infty \discont(f,\frac{1}{n})\)
    🔗

    Proof.

    🔗
    Solution.
    \(x\in \discont(f)\) \(\iff\) \(\osc(f,x)\gt\epsilon\) for some \(\epsilon\gt0\) \(\iff\) \(\osc(f,x)\ge1/n\) for some \(n\in \N\) \(\iff\) \(\osc(f,x)\ge\frac{1}{n}\) for some \(n\in \N\) \(\iff\) \(x\in \Cup_{n=1}^\infty \discont(f,\frac{1}{n})\)
    🔗
    🔗
    🔗
    Solution 5.
    \(m^*(\discont(f))=0\)\(\epsilon\gt 0\)\(\I\)\(\discont(f)\)\(\epsilon\text{.}\)
    🔗
    So, instead of proving that \(m^*(\discont(f))=0\) we will show that \(m^*(\discont(f,1/n))=0\) for all \(n\in \N\)
    🔗

    Half of the proof of the Riemann Lebesgue theorem.

    Suppose that \(f\) is integrable over \(I=[a,b]\) and \(M=\sup(f(I)), m=\inf(f(I))\text{.}\) For any \(\epsilon\gt0\) there is a partition \(P\) so that (Get the oscilation to appear.)
    🔗
    Solution 1.
    \(\epsilon \gt U(f,P)-L(U,P) = \Sum_{k=1}^n(\sup(f[I_k])-\inf(f[I_k]))\cdot\ell(I_k) = \Sum_{k=1}^n\osc(f,I_k)\cdot\ell(I_k)\)
    🔗
    🔗
    Now fix any \(\alpha\gt0\) and restrict this sum to \(Z_{\alpha}\) the set of all \(k\) with \(\osc(f,\alpha)\gt \alpha\text{.}\) Dropping some terms makes the sum smaller so that,
    🔗
    Solution 2.
    \(\epsilon \gt \Sum_{k=1}^n\osc(f,I_k)\cdot\ell(I_k) \ge \Sum_{k=Z_{\alpha}}\osc(f,I_k)\cdot\ell(I_k) \gt \Sum_{k=Z_{\alpha}}\alpha\cdot\ell(I_k)\)
    🔗
    🔗
    Divide both sides by \(\alpha\)
    🔗
    Solution 3.
    \(\epsilon/\alpha \gt \Sum_{k=Z_{\alpha}}\ell(I_k)\)
    🔗
    🔗
    Fact (almost) If \(x\in \discont(f,\alpha)\text{,}\) and \(x\in I_k\) then \(\osc(f,I_k)\ge\alpha\text{.}\) Say something about a cover. (Homework: Fix this claim and prove it)
    🔗
    Solution 4.
    Every \(x\in \discont(f,\alpha)\) is therefore in some \(I_k\) with \(k\in Z(\alpha)\text{.}\) \(\{I_k\mid k\in Z(\alpha)\}\) is a cover of \(\discont(f,\alpha)\)
    🔗
    🔗
    Make a conclusion
    🔗
    Solution 5.
    \(m^*(\discont(f,\alpha)\le \Sum_{k=Z_{\alpha}}m^*(I_k)=\Sum_{k=Z_{\alpha}}\ell(I_k))\lt \epsilon/\alpha\text{.}\)\(\epsilon\to 0\)\(m^*\discont(f,\alpha)=0\text{.}\)\(\discont(f)=\Cup_{n=1}^\infty \discont(f,\alpha)\text{,}\)\(m^*(\discont(f))=0\text{.}\)
    🔗
